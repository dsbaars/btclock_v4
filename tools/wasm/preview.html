BTClock IDF-port screen preview

Exercises the ESP-IDF C++ port's screen-layout helpers (idf_cpp_proto/main/screens/common.cpp + fee_rate_layout.hpp) compiled via Emscripten. Each screen cell below maps to one 2.13" EPD panel in the 7-panel rotation.

View mode

Text cells: shows what each panel's data layout resolves to as plain strings — fast, cheap, no font rendering. Pixel preview: runs the actual main/screens/*.cpp renderers + stb_truetype font rasterizer and draws each panel onto a canvas. Without AA this is the exact 1-bpp frame the e-paper paints (122x250 logical, rotated 180° to match REV_B solder orientation); with AA enabled the preview uses the raw grayscale alpha stb_truetype produces BEFORE the 1-bpp threshold — smoother glyph edges, not what the EPD shows.
